# الميزان الذكي — مشروع Android أصلي

هذا مشروع أندرويد أصلي بلغة Kotlin (ليس PWA أو WebView)، بحد أدنى Android 6.0 ويدعم Android 13.

## الوظائف
- إدخال الوزن الإجمالي والسعر الإجمالي وحساب سعر الجرام تلقائياً.
- عرض سعر 100 جرام وسعر الكيلو.
- حساب السعر لأي وزن مطلوب.
- لوحة أرقام داخلية؛ المس الحقل ثم استخدم الأزرار.
- وضع بيع مباشر لإضافة الوزن الحالي للسجل ثم تفريغ خانة الوزن المطلوب.
- سجل عمليات محفوظ محلياً على الجهاز.
- مشاركة السجل عبر تطبيقات الهاتف.
- يعمل دون اتصال بالإنترنت ولا يطلب صلاحيات إنترنت.

## بناء ملف APK
يتطلب Android Studio حديثاً وJDK 17 وAndroid SDK Platform 35:
1. فك ضغط المشروع.
2. افتح مجلد `MizanAndroid` في Android Studio.
3. انتظر مزامنة Gradle.
4. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5. ستجد الملف في:
   `app/build/outputs/apk/debug/app-debug.apk`

يمكن أيضاً البناء من الطرفية بعد تثبيت Gradle وAndroid SDK:
`gradle assembleDebug`

## بناء تلقائي عبر GitHub Actions
يوجد ملف `.github/workflows/build.yml`. ارفع المشروع إلى مستودع GitHub، ثم شغّل workflow باسم Build Android APK من تبويب Actions. سيظهر APK كـ Artifact قابل للتنزيل.

## ملاحظة مهمة
هذه الحزمة هي مشروع Android كامل قابل للبناء، وليست ملف APK جاهزاً. بيئة التنفيذ المستخدمة هنا لا تحتوي Android SDK أو Gradle، لذلك لم أستطع تجميع APK فعلياً داخل هذه الجلسة.
